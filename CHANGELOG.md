# Changelog

All notable changes to this project are documented in this file.

## 0.1.1 - 2026-08-22

### Changed

- `homepage` now points to the package's documentation page at
  <https://blackswampai.com/n8n-nodes/studiocms/> instead of the GitHub README.
  Metadata only: the package name, node paths, dependencies, and behaviour are
  unchanged.

## 0.1.0 - 2026-08-12

### Added

- StudioCMS API credentials with an n8n credential connection test.
- Connection check operation.
- Create, delete, get, get many, and update operations for categories, folders, pages, and tags.
- Scoped public npm package metadata for the BlackSwampAI organization.
- GitHub Actions publishing with npm provenance and first-publication bootstrap guidance.
