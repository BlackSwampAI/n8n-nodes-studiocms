# StudioCMS API and operation matrix

Accessed 2026-10-05. Routes use the authenticated REST v1 base
`/studiocms_api/rest/v1`. Rows describe the 21 currently advertised operations. Contract tests
cover request construction, list normalization, limits, and errors; the Page Get/Get Many rows
also have one compiled-node live execution against disposable StudioCMS 0.6.1, described in the
[live smoke report](live-smoke-2026-10-05.md).

The node currently retains its established programmatic architecture. This migration does not
claim that multiple HTTP calls alone require programmatic style: Update/Delete perform an existing
resource GET before a guarded mutation, and shared execution code diagnoses conditional
transport failures. A declarative-routing assessment was explicitly deferred at the user's
direction; no declarative conversion was included. The [testing guide](testing.md) records the
remaining UI/runtime evidence boundary.

The release-schema evidence for the embedded Page user variants and their fixture provenance is
in [testing](testing.md#studiocms-page-response-fixtures). Live evidence covers only StudioCMS
0.6.1 and these listed operations; it does not claim broad latest-version compatibility or n8n
editor qualification.
