# Batch handoff template

Record scope, API evidence, files changed, exact test results, live fixture safety and cleanup,
actual compiled-node/editor evidence separately, limitations, and decisions requiring orchestrator
review. For ordinary REST operations, assess routing, expressions, pagination, and response hooks;
record concrete behavior and evidence without assuming that multiple requests alone require
programmatic style. Builders do not commit, push, publish, tag, or open a PR unless the user
explicitly authorizes that action.

For this StudioCMS template migration, declarative conversion was explicitly deferred by the user;
the API matrix records the exception and does not claim technical impossibility.
